查看如何用 Codex 把 ChatGPT 對話整理成專案架構

本機操作從 ChatGPT 卡片的「用 Codex 自動整理」開始。選擇工作方式後，在桌面 Codex 按送出。

  • 只整理架構：查看已有的架構，或依這則對話整理出階段、模組和驗收項目。符合條件時，以原對話名稱存回看板卡片。回到看板的 ChatGPT 分頁，在原對話卡片查看架構。Codex 應用程式會保留這則對話，標題加上「[ 回CHATGPT ]」。這次整理不會列在看板的 Codex 工作清單。
  • 整理架構並實作驗收：指定本機專案資料夾，已有架構就選一個未驗收項目。尚無架構時，Codex 先整理並找出第一個條件明確且可驗收的項目。整理、實作和測試在同一則 Codex 對話進行，條件不足時會先釐清。這則工作對話的標題會加上「[Chatgpt 轉移 CODEX]」，並列在看板的 Codex 工作清單。

在同一台電腦選「整理架構並實作驗收」，Codex 會直接讀取本機看板上的架構。跨電腦時，在 ChatGPT 卡片點「下載架構包」，把 .codex-plan.json 交給接手者。接手者在本機看板點「匯入架構包」，選一個未驗收項目和本機專案資料夾，再點「開啟 Codex」並在桌面 Codex 按送出。
